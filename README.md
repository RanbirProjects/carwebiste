# Car collection webiste ® MERN Clone

This project is a MERN stack clone of the N4 Studio® profile page on Awwwards.

## Project Structure

- `backend/` — Node.js, Express, MongoDB API
- `frontend/` — React app

## Setup Instructions

### 1. Backend

```
cd backend
npm install
# Set your MongoDB URI in .env (default: mongodb://localhost:27017/n4studio)
npm run dev
```

### 2. Frontend

```
cd frontend
npm install
npm start
```

The frontend will run on http://localhost:3000 and the backend API on http://localhost:5000.

## Features
- Studio profile info
- Projects list
- Awards list
